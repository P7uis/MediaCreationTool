This is a vibecoded tool that is developed as a better alternative to the microsoft camera app.
Currently there is only a basic easy mode. There is a plan to later extend this with a expert/advanced mode with more controls over the image and audio depending on browser capabilities.
Developed and kinda tested with chrome browser.

The tool is installable as a Progressive Web App. After the first online visit, the app shell is cached so it can open offline too. Capture/export still depends on the browser's camera, microphone, screen-capture and file APIs, but existing direct-to-disk and OPFS-backed saving paths keep large recordings from piling up in RAM where the browser supports them.

Next up on my list is changing the file encoding to go with more mainstream formtats than webm files.

Feedback and bugfindings are very welcome as this is still in active development.
